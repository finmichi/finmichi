# 手機首屏與偏差顯示

已選帳本時預設進入「交易記帳」，帳本新增／編輯表單預設收合；「管理目前帳本」可展開／收起，「新增其他帳本」可建立新帳本。尚無帳本時仍直接顯示新增表單。

偏差百分比僅在畫面使用既有 BigInt ROUND_HALF_UP 顯示2位小數；API與警告判斷維持原有精確值。例如23.0769230769%顯示23.08%，0.0307692308%顯示0.03%；不以畫面值重新判定5%門檻。
