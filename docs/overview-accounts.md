# 總覽帳戶餘額

總覽重用 `ReportTree` 顯示「資產」「負債」與完整科目樹。第一層為資產／負債，第二層為根科目；預設只展開第一層，第三層以下由使用者展開。桌面為表格，手機為卡片，展開按鈕支援鍵盤及 `aria-expanded`。

金額直接使用同日 `/reports/balance-sheet` 的 `totals.assets`、`totals.liabilities` 與各科目的 `book_amount`，明確標為「帳面值」。不將市值混入帳面小計，也不在前端重算匯率。外幣另列科目自身的 `own_original_amount`（沿用原本總覽的原幣方向），本位幣原幣欄為「—」。父科目的帳面值包含子科目，不另外加總子層以避免重複計算。

預設隱藏整個分支都沒有餘額的科目；父科目自身及子樹合計為零、但子科目仍有互相抵銷的非零餘額時，保留其祖先路徑，以免遺失非零帳戶。另提供「顯示 0 餘額」。判斷使用十進位字串與 BigInt，不轉成 JS Number。

展開 ID 與零餘額偏好存於 `finmichi-overview-expanded`，以帳本 ID 分開；空展開集合也會保存。localStorage 讀寫、JSON 損壞及配額／隱私限制皆有容錯。切換帳本時重建偏好元件，資料尚未載入時不顯示前一帳本的餘額。

本 PR 無 migration、無新增 API、無後端或權限變更。既有備份 schema、查詢與報表計算口徑不變。測試只用合成資料，需檢查 4 尺寸、淺／深色、重新整理、切換帳本、鍵盤、零餘額與 API 小計一致性。
